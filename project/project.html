Here are some of my research and development projects

My_OrcaHand++
A national-level undergraduate innovation and entrepreneurship project, serving as project leader. My_OrcaHand++ is a customized robotic hand control project built around Feetech servos, visual calibration, motion programming, and gesture-guided grasping. The system migrates the original control interface to the corresponding Feetech servo commands and integrates the main hardware functions into a unified desktop control UI.
